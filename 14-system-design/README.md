# System Design

This module is the culmination of the entire Backend Roadmap. You will take everything you have learned—Node.js, Databases, Authentication, Caching, Message Queues, WebSockets, and Microservices—and combine them to design massive, scalable, real-world systems.

## What You Will Learn
* The 13-step System Design Process
* Functional vs. Non-Functional Requirements
* Capacity Estimation (RPS, Storage, Bandwidth)
* Scalability (Vertical vs. Horizontal, Sharding)
* The CAP Theorem and Consistency Models
* Designing 14 real-world systems (URL Shortener, Chat App, E-commerce, etc.)
