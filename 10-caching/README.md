# Module 10: Caching & Performance

This module covers the critical topic of caching in modern web architectures. You will learn about different levels of caching, from the browser to the CDN, API Gateway, and database layer.

## Topics Covered:
- Cache Invalidation Strategies
- Browser Caching (Cache-Control, ETag)
- Content Delivery Networks (CDNs)
- Server-Side Caching (Redis, Memcached)
- Database Query Caching
- The Cache Stampede Problem
