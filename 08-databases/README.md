# Module 08 — Databases & SQL

## Purpose

This module is the canonical reference for databases in this repository. It covers everything from fundamental SQL commands to advanced indexing, normalization, transactions, and NoSQL databases.


## Topics Covered

- SQL syntax, Joins, Constraints, and Keys
- Database Normalization
- ACID Transactions
- Query Optimization and Indexing
- Advanced SQL (Window functions, CTEs)
- ORMs and Database Connections
- Cloud Databases and Multi-Region Deployments
- Data Warehouses vs Data Lakes
- Real-World Database Architecture
- Comprehensive Interview Questions and Cheat Sheet


## Learning Objectives

After completing this module, you will be able to:

- Write complex SQL queries with joins, subqueries, and window functions.
- Design normalized database schemas to prevent data anomalies.
- Understand and apply proper indexing to optimize query performance.
- Describe the differences between SQL and NoSQL, and choose the right database for your project.
- Understand the mechanics of ACID transactions and isolation levels.
- Safely connect and interact with databases from a backend application.
