# Microservices

This module covers the architectural shift from building a single large application (a Monolith) to a distributed system of small, independent services (Microservices).

You will learn how to draw service boundaries, how services talk to each other, how to handle data that spans multiple databases, and how to keep the system reliable when parts of it inevitably fail.

## What You Will Learn
* Monoliths vs. Modular Monoliths vs. Microservices
* API Gateways and Service Discovery
* Distributed Data and Distributed Transactions (Sagas, 2PC)
* Event-Driven Architecture (EDA)
* Reliability patterns: Retries, Timeouts, and Circuit Breakers
* Observability and Deployment (Docker, Kubernetes)
