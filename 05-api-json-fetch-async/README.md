# 🔌 Day 3: APIs, JSON, Fetch & Async JavaScript

Welcome to the **APIs & Asynchronous JavaScript** integration module! This is where all the puzzle pieces (HTML, CSS, JavaScript) come together to build dynamic, data-driven, real-world web applications.

## 📁 What's Inside?

* **[api-json-fetch-async.md](./api-json-fetch-async.md)** — A comprehensive reference guide covering:
  * What an **API** is and the frontend-backend communication model (the waiter analogy).
  * **JSON** format rules vs JavaScript Objects.
  * Making web requests using the **Fetch API**.
  * **Asynchronous JavaScript** (Callbacks, Promises, and `async/await`).
  * A step-by-step **Mini Project Specification** (API User Card App).
  * 10 Theory questions, 10 Coding practice tasks, and a Final Assignment.

---

## 🎯 Learning Objectives

By the end of this module, you should be able to:
* Describe what an **API** is and how it routes requests and responses.
* Format and parse data between **JSON strings** and **JavaScript Objects**.
* Write asynchronous network calls using `fetch` with the `async/await` syntax.
* Implement structured error handling inside async functions using `try/catch` blocks.
* Filter fetched data dynamically based on user input in real-time.
* Build a complete mini-project that connects to a real external API.
